# AutoLabel Dock 功能清单（UI 重设计核对表）

> **用途**：UI 重设计（方案 A / B 落地）时逐项核对，防止界面改版造成功能缺失。
> **用法**：每改造一个界面区域，就把对应区块的条目逐一在新 UI 中验证并勾选；无法平移的功能必须在设计稿中显式安排去处，不允许静默丢弃。
> **来源**：由 `src/` 代码逐文件提取（2026-08-29，commit a81f036 + 工作区改动）。
> 配套架构文档见根目录 `CODE_OVERVIEW.md`。
