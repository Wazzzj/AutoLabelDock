AUTOLABEL DOCK · UI 结构重设计 · 两方案 × 全页面

两套骨架，每个页面都有设计稿

在「统一工作台」与「训练流水线」两个方向上，把现有程序的每个页面（主页 / 标注 / 分类 / 预览 / 训练 / 模型 / 小工具）都重画了一遍。 所有功能点均对照 FEATURE_INVENTORY.md 清单落位；示例数据沿用真实领域场景（胶环密封检测 · cats-dogs 分类）。点击任意卡片打开可交互大图。

现状参照 六个平铺页签平级并列，闭环关系不可见；标注三栏常驻挤压画布；训练与标注割裂；批量任务 / GPU / 队列状态无法跨页感知。

选型建议

A 稳、B 亮，且可杂交。A 改动面最小（壳层重构、面板内保留），适合先落地；B 把闭环讲得最清楚，适合对外演示。两套不互斥——常见杂交是 A 的骨架 + B 的流水线顶栏（把图标导航换成阶段条）。

功能完整性：每个页面落位均对照 FEATURE_INVENTORY.md 的 14 区块 ~180 项清单；两份已知待决点——小工具在方案 B 中的归属（现定"导出部署"阶段）、⌘K 命令面板为新增功能（非旧功能迁移）。
