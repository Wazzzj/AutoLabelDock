浏览器直接打开本文件即可预览；原型模拟「标注页」主界面（数据版本树 + 文件列表 | 画布 + 标注 overlay | 标注列表/属性/统计），同一示例场景、仅主题不同。

说明：这是高保真静态原型（HTML/CSS/SVG），用于直观对比三套设计语言的差异——
· 方案 B 的毛玻璃效果用了 CSS backdrop-filter，PyQt5 QSS 无法原生实现，落地时以「半透明面板 + 渐变 + 高光边」模拟（详见 UI_SCHEMES.md）；
· 画布中的示例图像与标注框（矩形框 / 实例分割多边形 / OBB 旋转框 / 未确认虚线 / 标签胶囊）为同一场景在三套主题下的渲染，展示类别色与状态色的对比度差异。
· 若需程序真实截图，需先安装依赖（pip install -r requirements.txt）运行 python main.py。
